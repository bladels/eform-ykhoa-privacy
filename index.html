1. Overview (Tổng quan)

EN Eform Y Khoa - Trợ Lý Bệnh Án Điện Tử (Full edition) and Eform Lite - Gõ Tắt & Nhập Liệu Y Khoa (Lite edition) are browser extensions designed for healthcare professionals to assist with clinical documentation (multi-line text expansion/hotstrings, copy/paste restoration, keyboard typing assistance, and clinical decision-support calculators). We are committed to protecting user privacy and medical data confidentiality.

VI Eform Y Khoa - Trợ Lý Bệnh Án Điện Tử (Bản Đầy Đủ) và Eform Lite - Gõ Tắt & Nhập Liệu Y Khoa (Bản Gọn Nhẹ) là các tiện ích trình duyệt hỗ trợ bác sĩ và nhân viên y tế soạn thảo bệnh án điện tử (gõ tắt đa dòng, khôi phục copy/paste, hỗ trợ nhập liệu qua bàn phím và tính toán các công thức lâm sàng). Chúng tôi cam kết bảo vệ quyền riêng tư của người dùng và tính bảo mật của dữ liệu y khoa.

2. Data Collection & Storage (Thu thập & Lưu trữ dữ liệu)

EN

  • Zero Developer Server Collection: Neither extension collects, transmits, stores, or sells any personal data, patient health information (PHI), or browsing history to any developer-controlled server or third-party analytics service.
  • Persistent Local Storage (chrome.storage.local): User-defined hotstrings (text templates), extension preferences (typing speed, workday/holiday calendar mode, authorized domains, and in the Full edition the user's optional personal Gemini API key), local hotstring usage frequency counts (clinical_hotstring_usage), de-identified offline bilingual glossary entries (clinical_bilingual_cache), and up to 20 automatic backup snapshots are stored exclusively on your local device using chrome.storage.local.
  • Optional Browser Profile Sync (chrome.storage.sync): If enabled by the user (Chrome or Microsoft Edge account sync), compressed hotstrings and non-sensitive user preferences (typing speed, calendar/holiday options, shortcuts, domain toggles; never patient PHI and never personal Gemini API keys) are stored in your browser's own chrome.storage.sync area to sync across your Chrome/Edge profiles without any developer server.
  • Ephemeral Session Storage (chrome.storage.session): Temporary workspace data created during active clinical workflows (bilingual translation drafts bilingual_eform_session in both editions; and copied old medical record snapshots copied_old_eform_record, transient AI Eform inputs/outputs, and volatile cross-tab prescription safety check buffers volatile_rx_* in the Full edition) is stored strictly in volatile chrome.storage.session memory and is automatically purged when the browser closes.

VI

  • Không thu thập dữ liệu về máy chủ: Cả hai phiên bản đều KHÔNG thu thập, truyền tải, lưu trữ hay bán bất kỳ dữ liệu cá nhân, thông tin bệnh nhân (PHI) hay lịch sử duyệt web nào về máy chủ của nhà phát triển hoặc bên thứ ba.
  • Lưu trữ cục bộ trên thiết bị (chrome.storage.local): Danh sách từ viết tắt, cài đặt cá nhân (tốc độ gõ, tùy chọn lịch làm việc/ngày lễ, danh sách tên miền đã kích hoạt, và ở Bản Đầy Đủ là khóa Gemini API cá nhân nếu người dùng tự nhập), bộ đếm tần suất dùng mã cục bộ (clinical_hotstring_usage), kho từ vựng song ngữ đã ẩn danh (clinical_bilingual_cache) cùng tối đa 20 bản sao lưu lịch sử được lưu hoàn toàn trên thiết bị của bạn thông qua chrome.storage.local.
  • Đồng bộ tùy chọn qua tài khoản trình duyệt (chrome.storage.sync): Khi được bật, bộ từ viết tắt và cài đặt không nhạy cảm (tốc độ gõ, lịch làm việc, phím tắt, danh sách trang web bật/tắt — không bao gồm khóa Gemini API và không chứa dữ liệu bệnh nhân) được nén và lưu qua chrome.storage.sync để đồng bộ giữa các máy dùng cùng tài khoản Google Chrome hoặc Microsoft Edge mà không qua máy chủ riêng.
  • Lưu trữ phiên tạm thời (chrome.storage.session): Dữ liệu tạm thời khi thao tác trên bệnh án (bản nháp dịch song ngữ bilingual_eform_session ở cả hai phiên bản; bản sao bệnh án cũ copied_old_eform_record, nội dung phiên AI Eform và bộ đệm đối chiếu an toàn đơn thuốc giữa các tab volatile_rx_* ở Bản Đầy Đủ) chỉ được giữ trong bộ nhớ phiên chrome.storage.session và tự động xóa sạch khi đóng trình duyệt.

3. Optional AI API & Bilingual Features (Tính năng API AI tùy chọn & Dịch song ngữ)

EN

  • Lite Edition (Eform Lite - Gõ Tắt & Nhập Liệu Y Khoa): Performs zero background network requests and contains no Gemini API integration or API key storage. Its Dịch bệnh án (Bilingual Translation) helper scrapes active Eform fields locally, automatically masks patient identifiers via redactClinicalPii() before previewing/copying a structured translation prompt to the clipboard, and only optionally opens the public gemini.google.com web UI when the user clicks to launch it.
  • Full Edition (Eform Y Khoa - Trợ Lý Bệnh Án Điện Tử):
    • Automatic background AI extraction (autoAiSmartScrape) is disabled by default.
    • AI features run only when the user explicitly opts in and clicks an AI action button (such as the opt-in Gemini API analysis button or opening a prepared prompt for the user's own https://gemini.google.com session).
    • Before any clinical text leaves the browser or is copied for AI assistance, an automatic PII redaction engine (redactClinicalPii) masks patient identifiers (patient names, dates of birth, ID/CCCD/BHYT numbers, PIDs/VisitCodes, phone numbers, email addresses, and street addresses) while preserving clinical terminology, and displays a redacted preview with the masked item count for user review.
    • When using the opt-in Gemini API workflow, de-identified clinical text is transmitted directly from the user's browser to Google's official Gemini API (https://generativelanguage.googleapis.com) using the user's own personal API key passed via the x-goog-api-key HTTP request header (never in URL parameters and never via a developer proxy). The developer has no access to the API key or prompt contents.

VI

  • Bản Lite (Eform Lite - Gõ Tắt & Nhập Liệu Y Khoa): Thực hiện 0 yêu cầu mạng nền / API từ xa và không tích hợp Gemini API hay lưu API Key. Tính năng Dịch bệnh án (Bilingual Translation) đọc các trường Eform tại chỗ, tự động che thông tin định danh qua redactClinicalPii() trước khi hiển thị/copy prompt dịch vào clipboard và chỉ mở trang web công khai gemini.google.com khi bác sĩ chủ động bấm nút.
  • Bản Đầy Đủ (Eform Y Khoa - Trợ Lý Bệnh Án Điện Tử):
    • Tính năng tự động đọc bằng AI (autoAiSmartScrape) được tắt mặc định.
    • Mọi tính năng AI chỉ chạy khi người dùng chủ động bật/bấm nút xác nhận (nút phân tích qua Gemini API Opt-in hoặc sao chép sang phiên https://gemini.google.com của chính người dùng).
    • Trước khi dữ liệu được gửi hoặc sao chép, bộ lọc ẩn danh tự động (redactClinicalPii) sẽ che các thông tin định danh cá nhân (họ tên bệnh nhân, ngày sinh, số CCCD/CMND/BHYT, mã PID/VisitCode, số điện thoại, email, địa chỉ) mà vẫn giữ nguyên thuật ngữ y khoa, đồng thời hiển thị bản xem trước và số mục đã ẩn danh để bác sĩ kiểm tra trước khi gửi.
    • Khi chọn phân tích qua Gemini API, văn bản đã ẩn danh được gửi trực tiếp từ trình duyệt tới API chính thức của Google (https://generativelanguage.googleapis.com) bằng khóa API cá nhân của người dùng qua HTTP header x-goog-api-key (không gắn vào URL và không đi qua máy chủ trung gian của nhà phát triển).

4. Permissions Usage (Giải trình quyền truy cập)

EN

  • Optional Host Permissions (http://*/*, https://*/* — Per-Domain Opt-In): Neither extension requests blanket <all_urls> host access at install time. Scripts do not run on websites automatically. Only when the user explicitly clicks "Kích hoạt trên trang này" (Activate on this site) or enables a specific hospital EMR/Eform domain does the browser prompt via chrome.permissions.request for that single origin, registering dynamic scripts strictly for user-authorized origins. Major cloud/office web apps (Google Docs, Microsoft 365, GitHub, Facebook, YouTube) are excluded from the copy/paste restoration helper.
  • tabs: Used solely to read the active tab's hostname/URL so the Side Panel can display per-site activation status, verify origin permissions, and target the active EMR/Eform tab when inserting typed text. No browsing history is recorded or transmitted.
  • scripting: Used in both editions to dynamically register and inject the text-expansion and copy/paste restoration scripts strictly on domains explicitly authorized by the user, and on-demand when the user clicks to read or fill active Eform fields (including bilingual Eform fields in both editions, or old record copying / collapsible section expansion in the Full edition).
  • storage: Used to persist local preferences/hotstrings/backups (chrome.storage.local), optional compressed browser profile sync (chrome.storage.sync for hotstrings and non-sensitive settings across Chrome/Edge, excluding personal API keys), and ephemeral in-memory session drafts (chrome.storage.session in both editions).
  • sidePanel: Displays clinical calculators, hotstring management, and typing helpers in the browser Side Panel alongside the active EMR/Eform page.
  • clipboardRead / clipboardWrite: Used strictly when the user triggers copy/paste shortcuts (Ctrl+Alt+C, Alt+Shift+C, Alt+Shift+V, Ctrl+Alt+V, Ctrl+Shift+V), clicks Copy/Paste buttons in the Side Panel, or expands a hotstring containing {{clipboard}}.

VI

  • Quyền truy cập tên miền tùy chọn (optional_host_permissions: http://*/*, https://*/* — Cấp quyền theo từng trang): Tiện ích không xin quyền <all_urls> mặc định và không tự chạy trên các trang web khác. Chỉ khi bác sĩ bấm "Kích hoạt trên trang này" trên cổng bệnh án điện tử (EMR/Eform) đang mở, trình duyệt mới hỏi cấp quyền cho đúng tên miền đó và đăng ký script động cho các trang đã cấp phép.
  • tabs: Chỉ dùng để kiểm tra tên miền của tab đang mở nhằm hiển thị trạng thái Bật/Tắt theo trang và định vị đúng tab bệnh án khi chèn văn bản. Không lưu trữ hay gửi lịch sử duyệt web.
  • scripting: Dùng ở cả hai phiên bản để đăng ký và nạp script nhập liệu/khôi phục copy-paste trên đúng các tên miền người dùng đã cấp quyền, đồng thời đọc/điền các trường Eform đang mở khi bác sĩ bấm nút.
  • storage: Lưu từ viết tắt, cài đặt, sao lưu cục bộ (chrome.storage.local), đồng bộ tùy chọn theo tài khoản trình duyệt (chrome.storage.sync trên Chrome/Edge cho bộ gõ tắt và cài đặt không nhạy cảm, loại trừ API Key) và dữ liệu phiên tạm (chrome.storage.session ở cả hai phiên bản).
  • sidePanel: Hiển thị bộ công cụ lâm sàng và quản lý từ viết tắt ở thanh bên trình duyệt ngay cạnh trang bệnh án đang mở.
  • clipboardRead / clipboardWrite: Chỉ sử dụng khi người dùng thực hiện phím tắt hoặc nút Copy/Paste, hoặc sử dụng biến {{clipboard}} trong mẫu từ viết tắt.
